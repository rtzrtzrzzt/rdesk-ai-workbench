# RDesk 1.2.0

本版集中优化输入框、多工作区导航和设置层级，并完善本机任务的批准模式。

## 界面与工作区

- 输入框左侧改为加号上传，支持任意扩展名；移除文件库和本次任务设置按钮。模型与思考强度合并为右侧菜单，位于上下文指示器旁。
- 批准方式放在加号旁，明确显示当前任务将采用的权限模式。
- 侧栏可以同时展开多个工作区，直接查看并进入各自对话；切换工作区保留未发送的聊天草稿。
- 设置按通用、模型与连接、Agent 行为、扩展、权限与隐私、数据与维护、API 服务、高级与诊断组织。任务、工作区、规则及 API 配置进入各自二级页。
- 常用字段直接可见，模型参数、任务预算、提示词模板、能力声明、配置来源、存储明细和诊断详情默认折叠，原有高级功能仍可展开使用。去掉重复概览，收起和切页保留草稿与待核对状态；校验失败时展开错误所在区域并允许定位。

## 批准与文件访问

- **手动审批：** 本机所有者任务的工具操作逐项请求人工批准，包括读取操作；问答及协作等待继续使用各自交互协议。
- **智能审批：** 沿用本地模型审核；不确定或审核失败时拒绝，不静默切换批准方式。
- **完全开放：** 仅本机所有者明确确认的新任务可使用，跳过人工和模型审核，文件工具可访问工作区外目录。命令使用服务账号的系统权限，不能视为操作系统沙箱。
- 完全开放仍保留受保护凭据路径、文件版本、操作记录及账号归属边界；不能保存为用户、工作区或项目默认，也不能发布给外部 Agent API。子任务仍受委派工具与范围约束。

## 验证范围

- 沿用本次开发已完成的114项直接相关后端回归，以及真实 Chrome 和本地 Qwen 的四个小任务验收，覆盖人工、智能和完全开放模式、文件读写与工作区外访问。
- 设置改版另完成11组真实 Chrome 流程检查，包含临时工作区实际保存、隐藏字段与继承保留、真实409版本冲突、跨页草稿、模型模板与 API 资料路径校验，以及390/360px窄屏。页面脚本异常及隐藏控件聚焦错误均为0。
- 本版发行重新核对版本信息、生产前端构建和实际源码包校验，不重跑 Aider 榜单或推定模型效果提升。正式用户偏好和模型配置在界面验收后保持原值，临时工作区通过正常移除流程清理。
- 一次性 API 密钥的组件保留逻辑已核对，本轮设置验收没有实际生成密钥或对外发布服务。Windows/macOS、真实手机硬件、外部设备与公网 TLS 连通性仍需对应环境验证。详见[实现与验收记录](../implementation-status.md)。

## 升级与发行范围

- 数据库迁移头仍为 **040_agent_api**，相对1.1.0没有新增数据库迁移；更早版本仍须遵循相应迁移、备份及兼容性要求。
- 产品内净化备份的既有 schema 审核限制不变，不将源码包或目录复制视为完整数据备份。升级流程见[原生发行说明](../../runtime/distribution/README.md)。
- 源码 ZIP 包含预构建前端、双语 README、清单、SBOM 与许可材料，并附带 SHA256 和构建报告；不包含模型权重、用户文件、对话、数据库、凭据、私有部署配置、验收记录或设计参考压缩包。

## English

RDesk 1.2.0 simplifies the composer, combines model and reasoning controls, adds independently expandable workspace groups, and reorganizes settings into everyday choices, secondary pages and collapsed advanced sections. Existing fields, drafts and save/conflict semantics remain available.

Owner tasks offer manual, smart and explicitly confirmed full-access approval. Full access can reach files outside the workspace under the service account; it is not an OS sandbox. Protected credential paths, account/API boundaries, file-version checks and delegation limits remain. This mode cannot become a persisted default or be exposed through the Agent API.

Validation includes the existing 114 directly related backend regressions and four real local-model tasks, plus 11 settings workflows in real Chrome with 390/360px viewports. The release rebuilds the production frontend and validates its source archive; no new benchmark score is claimed. The schema head remains `040_agent_api`, with no new migration since 1.1.0. Platform, public-network and product-backup limitations remain as documented.
