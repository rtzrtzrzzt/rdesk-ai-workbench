# 生成预算、截止收尾与执行证据

模型上下文容量与常规单轮输出预算独立。`RunOptions.model_output_tokens` 默认 8192（256–1048576），包含提供方计入输出的思考 token；实际请求受到任务预算、连接显式上限及可用上下文共同约束。连接的自动输出不再将全部上下文余量作为输出额度。该选项不改变模型权重、上下文配置或思考档位，设置中的用户、工作区与单次任务覆盖沿用现有契约。

同一轮的自动续生成共用这一额度，已知用量累加；用量未知时不无依据继续。被截断、未完整提交的工具调用不执行。达到预算保留真实输出及断点，不把未完成状态改成成功。

`model_output_recovery_tokens` 为常规输出到顶后的单独恢复额度，默认2048（0–8192，0关闭）。每个Run最多一次，计入真实模型尝试和原有任务树总调用预算，不延长截止时间。只有已知正数输出用量、没有未完整提交的工具调用、仍有时间/轮数/调用预算时才可进入；纯思考耗尽也可获得这次机会。常规续生成与恢复内部续生成分别计量，不能将旧用量从新的恢复额度重复扣除，也不能循环重置额度。恢复阶段仍尊重连接显式输出上限、上下文容量及截止收尾的无工具限制。成功后清除恢复阶段但保留已使用标记；恢复再次耗尽则保留暂停与真实部分结果。已有冻结Run和未声明此字段的旧公开Agent版本不会因软件新默认值自动增加恢复额度。

设置 `deadline_seconds` 的任务使用 `finish_reserve_seconds`（默认 60，可设为 0 关闭软收尾）。实际预留最多为该任务初始时限的五分之一，短任务仍有执行阶段。运行时每次请求更新剩余时间和轮数；进行中的生成到达收尾边界时沿原生 abort/关闭链路中断，使用剩余时限发起无工具的收尾请求。收尾只说明已发生的修改、必要检查及真实结果、未验证项或阻塞，不能在时间不够时假报完成。硬截止继续由调度器负责，软收尾不延长它；工具、传输和子任务清理仍使用原有资源关闭协议。

预算是运行时实际观察，不是新的用户要求或授权。当前观察以固定来源和 Run 身份写入图历史，Qwen 使用模板认可的 tool-response 形式；原生历史的因果摘要仍包含这些观察，改变旧观察会使依赖的思考历史失效。这样保留真实用户边界、稳定系统前缀及已验证工具链，而不绕过规则变化、遗忘或权限过滤。

失败或取消且没有最终答复时，会话展示层根据同一 Run 的真实操作账本生成“工作台执行摘要”，分别报告工具成功、失败、结果待核对数量。该摘要不是模型答复，不设置最终 AI 答复锚点，也不推断测试通过。模型提示要求读取优先使用既有文件工具、验证时保留被测程序退出码与 stderr、使用已有日志分页；不全局更换 shell，也不把任何输出中的文字当作通用测试判定器。

## 文件预检与审核

`write_file/apply_patch` 的路径、当前版本、原文匹配及容量检查复用实际写入的只读准备函数；`edit_files` 复用已有整批准备。检查在模型审核前执行，错误参数不会先消耗一次模型审核。预检不产生写入，读取失败明确为未开始；真正提交仍在原文件锁、执行所有权和授权边界内重新验证，预检不充当提交凭证。

智能审批仅在同一个owner根Run已批准新建普通文件、完整确认版本链匹配、规则及后续用户输入未变化时，复用其创建授权处理该文件的非空编辑。每次仍生成独立Approval、参数摘要及真实来源`file_creation_policy`。不复用已有用户文件、规则/隐藏配置、命令、批次、子任务或外部API授权；不删除文件、不扩展工具/路径/网络权限，发生外部修改或证据缺口回到模型审核，手动审批保持手动。

模型审核只判断具体用户范围、授权和安全风险，不代替代码正确性或隐藏测试验收。文件审核获得有界的当前内容及同Run首次记录变更前快照，区分原接口与本轮新增helper；未保存任务开始瞬间的状态，因此不声称拥有完整原始接口。证据最多4文件/每文件64条变更，每侧文本3KiB、文本总24KiB，未知、截断与断链均明确标识，文件正文不能成为审核指令。

## 变更快照生命周期

同 Run、同内容版本复用内部快照，跨 Run 不共享。命令采集前后仍真实读取、散列并检测并发变化；完成采集后，仅保留 ChangeRecord 和仍 pending 的 capture 所需内容，释放临时 baseline 与无引用快照。数据库事务回滚不会丢失原快照，物理删除在提交后执行。

会话删除把 `change_snapshot` 纳入已有冻结清单及物理/数据库清理流程；用户项目原文件和独立文件制品继续按原有边界保留。本轮不扫除历史孤儿数据、不迁移用户目录。提交后进程崩溃或文件删除失败仍可能留下无引用物理文件；没有声称完成持久化 GC 或磁盘安全擦除。
